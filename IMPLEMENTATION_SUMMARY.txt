HOW IT WORKS
================================================================================

1. Doctor saves prescription and generates PDF (existing functionality)
2. Frontend receives patient data including phone_number
3. WhatsApp button appears with "Send Prescription via WhatsApp"
4. Doctor clicks button
5. Consent confirmation dialog appears
6. Doctor confirms patient consent
7. Phone number is validated and normalized
8. WhatsApp opens with:
   - Correct patient number (auto-filled)
   - Professional message (pre-filled)
9. Doctor downloads PDF and attaches it manually in WhatsApp
10. Doctor sends the message

================================================================================
PHONE NUMBER NORMALIZATION
================================================================================

INPUT EXAMPLES:
- 9876543210           → 919876543210 ✅
- +91 9876543210       → 919876543210 ✅
- 919876543210         → 919876543210 ✅
- +91-98765-43210      → 919876543210 ✅
- (91) 9876543210      → 919876543210 ✅

SAFETY FEATURES:
✅ Removes spaces, hyphens, brackets
✅ Handles +91, 91, and plain 10-digit formats
✅ Does NOT duplicate country code
✅ Validates 10-digit mobile number
✅ Throws clear error for invalid numbers
