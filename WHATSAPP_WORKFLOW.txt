================================================================================
SECURITY CHECKPOINTS
================================================================================

┌─────────────────────────────────────────────────────────────────┐
│                         SECURITY LAYER                          │
└─────────────────────────────────────────────────────────────────┘

1. Authentication Check
   └─> Is user logged in as doctor? ──> NO ──> Redirect to login
                                   └──> YES ──> Continue

2. Authorization Check
   └─> Does doctor have permission? ──> NO ──> Show error 403
                                   └──> YES ──> Continue

3. Patient Data Validation
   └─> Is patient selected? ──> NO ──> Show error "Select patient"
                          └──> YES ──> Continue

4. Phone Number Validation
   └─> Is phone valid? ──> NO ──> Show error "Invalid number"
                     └──> YES ──> Continue

5. Consent Confirmation
   └─> Did doctor confirm? ──> NO ──> Stop (do nothing)
                         └──> YES ──> Continue

6. Data Sanitization
   └─> Encode message with encodeURIComponent()
   └─> No sensitive data in URL parameters

7. User-Initiated Action
   └─> Direct user click required (prevents CSRF)
