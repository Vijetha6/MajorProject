MedInfo – Medicine Inventory & Sales page update

Files in this ZIP are an overlay update only:
- templates/index.html
- static/script.js
- static/style.css

How to apply:
1. Stop the Flask server (Ctrl+C in its terminal).
2. Make a backup copy of your current project folder.
3. Extract this ZIP into your existing project folder and allow these three files to be replaced.
4. Start the Flask server again using your normal command.
5. Log in as Medical Staff and open “Medicine Inventory & Sales” in the sidebar.

The new page places Search Location and Sell Medicine one below the other.
Sales History, Inventory, Expiry Alerts, login, database, and backend routes are not replaced by this overlay.
This ZIP intentionally does not include .env, databases, backups, or .git.
